# GitShamed!


A tiny project I built mostly to revise concepts I had learned theoretically but never really got around to implementing properly.

I didn't put much effort into making this a full-fledged application. No database, no deployment, and the frontend and backend aren't even connected. I just wanted to get my hands dirty with React, Node.js, Express, APIs, and a bit of AI integration.

It's nothing groundbreaking or particularly serious. Just a small experiment to revisit things I never properly learned in the first place.

Built for fun, practice and a little bit of GitHub bullying.
